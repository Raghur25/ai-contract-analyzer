# Vakeel Contracts API

AI-powered contract analysis for lawyers. Upload a PDF or text contract and get structured insights: key clauses identified, risks flagged, an overall risk level, and recommendations. Built for Indian contract law and powered by Google Gemini.

## Features

- **Upload** PDF and TXT contracts (up to 10 MB)
- **Text extraction** from PDFs with PyPDF2, with page and word counts
- **AI analysis** with the Google Gemini API, returning structured JSON
- **Structured output:** summary, contract type, key clauses (standard or not), risk flags with severity, overall risk level, and recommendations
- **MongoDB storage** for contracts and analysis results
- **Interactive API docs** (Swagger UI) generated by FastAPI

## Tech stack

| Area | Technology |
|------|------------|
| API | FastAPI, Uvicorn |
| Validation | Pydantic v2 |
| AI | Google Gemini (`google-genai`) |
| PDF parsing | PyPDF2 |
| Database | MongoDB (PyMongo) |
| Local services | Docker Compose (MongoDB + Mongo Express) |

## Getting started

### Prerequisites

- Python 3.11 or later
- Docker (for the local MongoDB), or any MongoDB instance you can connect to
- A Google Gemini API key from [Google AI Studio](https://aistudio.google.com/apikey)

### 1. Clone and install

```bash
git clone https://github.com/Raghur25/ai-contract-analyzer.git
cd ai-contract-analyzer

python -m venv .venv
# Windows (PowerShell)
.venv\Scripts\Activate.ps1
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Configure environment variables

```bash
cp .env.example .env      # Windows: copy .env.example .env
```

Edit `.env` and set:

| Variable | Description |
|----------|-------------|
| `MONGODB_URI` | MongoDB connection string |
| `GEMINI_API_KEY` | Your Google Gemini API key |
| `MONGO_ROOT_USERNAME`, `MONGO_ROOT_PASSWORD` | Credentials for the Docker MongoDB (optional) |
| `MONGO_EXPRESS_USERNAME`, `MONGO_EXPRESS_PASSWORD` | Mongo Express login (optional) |

The `MONGODB_URI` username and password must match the Docker MongoDB credentials.

### 3. Start MongoDB

```bash
docker compose up -d
```

This starts MongoDB on port `27017` and Mongo Express (a web UI for the database) on <http://localhost:8081>.

### 4. Run the API

```bash
uvicorn app.main:app --reload
```

- API: <http://127.0.0.1:8000>
- Interactive docs: <http://127.0.0.1:8000/docs>

## API endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/contracts/upload` | Upload a PDF or TXT contract |
| `GET` | `/contracts/` | List all uploaded contracts |
| `GET` | `/contracts/{id}` | Get one contract by ID |
| `POST` | `/analysis/analyse/{contract_id}` | Analyse a contract with Gemini |
| `GET` | `/analysis/` | List all analyses |
| `GET` | `/analysis/{analysis_id}` | Get one analysis by ID |
| `GET` | `/analysis/contract/{contract_id}` | List all analyses for a contract |

### Example

```bash
# 1. Upload a contract
curl -X POST http://127.0.0.1:8000/contracts/upload \
  -F "file=@samples/sample_nda.txt"
# -> {"message": "...", "id": "<contract_id>", "contract": {...}}

# 2. Analyse it
curl -X POST http://127.0.0.1:8000/analysis/analyse/<contract_id>

# 3. Fetch the result
curl http://127.0.0.1:8000/analysis/<analysis_id>
```

### Analysis result

```json
{
  "summary": "A one-way NDA between ...",
  "contract_type": "Non-Disclosure Agreement (NDA)",
  "key_clauses": [
    {
      "clause_title": "Term and Duration",
      "clause_text": "...",
      "explanation": "...",
      "is_standard": true
    }
  ],
  "risk_flags": [
    {
      "risk_title": "Unenforceable Post-Termination Non-Compete",
      "description": "...",
      "risk_level": "critical",
      "recommendation": "...",
      "clause_reference": "Clause 4"
    }
  ],
  "overall_risk_level": "high",
  "recommendations": ["..."]
}
```

Risk levels are `low`, `medium`, `high` or `critical`.

### Contract status

A contract's `status` field moves through: `uploaded` → `in_progress` → `analysed`, or `error` if the analysis fails.

## Notes and limitations

- Only the first 15,000 characters of a contract are sent to Gemini.
- Uploaded files are stored in `uploads/` and contain confidential client data. The folder is git-ignored.
- The AI output is a decision aid, not legal advice. A qualified lawyer should review every analysis.

## Security

- Never commit `.env`. It is listed in `.gitignore`.
- The default Docker credentials in `docker-compose.yml` are for local development only. Change them in `.env`, and don't expose MongoDB or Mongo Express to the internet.
- If an API key is ever committed by mistake, revoke it and create a new one.
